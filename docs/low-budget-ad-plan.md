# Low-Budget Ad Plan

No ad is launched by this plan. This is a readiness document for manual promotion only.

## Spend Levels

### $0 Baseline

- Post organically on Instagram and Facebook.
- Use stories for final 48-hour reminders.
- Share to personal network once, not daily.
- Ask 1-2 trusted local friends to share the evergreen event post.
- Post in local groups only where rules allow it.

### $5 Test

Use one Meta boost on a strong, simple asset:

- Asset: `simple-daggerheart-square.png` or `evergreen-find-table-square.png`
- Audience: 10-15 mile radius around Chandler, AZ
- Interests: tabletop games, board games, Dungeons & Dragons, fantasy, local events
- Goal: message, profile visit, or link click depending on available account setup

Success signal:

- One real comment, DM, share, or link click cluster from local people is enough to learn.

### $15 Test

Run two small boosts:

1. July 7 direct event post.
2. Evergreen recurring event post.

Keep each test short. Do not optimize endlessly.

### $30 Max Test

Run a simple split:

- $10 direct July 7 post.
- $10 evergreen Daggerheart-curious post.
- $10 newcomer reassurance post.

Stop if comments show confusion about date, location, price, or what a one-shot is. Fix copy before spending more.

## Targeting Notes

Primary geography:

- Chandler, AZ
- Mesa, AZ
- Tempe, AZ
- Gilbert, AZ
- Phoenix Valley

Interest ideas:

- tabletop roleplaying games
- board games
- Dungeons & Dragons
- fantasy games
- Critical Role adjacent fandom
- local game stores

Do not imply official affiliation with any brand or creator.

## Recommended Ad Copy

### Direct

Daggerheart one-shot in Chandler. Beginner-friendly, premade heroes, rules taught at the table. Scan or tap for current event details.

### Newcomer

Curious about tabletop RPGs but never knew where to start? This is a friendly one-shot with no homework, no rulebook, and no pressure to do character voices.

### Daggerheart-Curious

Heard about Daggerheart and want to try it without buying the book or building a character first? Pull up a chair.

## Measurement

Track manually:

- Comments asking for info
- DMs
- Link clicks if visible
- Shares
- Profile visits if visible
- Seats claimed
- Confusion themes

## Kill Criteria

Do not spend if:

- The event page is stale or missing dates.
- The QR/link route is wrong.
- Date/time/location are still changing.
- The post uses an unconfirmed July date.
- The asset has unreadable text at thumbnail size.
